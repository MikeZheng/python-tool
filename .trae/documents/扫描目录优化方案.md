# 扫描任务管理优化方案

## 1. 概念重构：从"扫描目录"到"扫描任务"

**核心变更**：
- 将页面名称从"扫描目录"改为"扫描任务"
- 重新设计页面结构，以任务为中心
- 扩展任务管理功能，包括创建、查看、编辑、暂停、取消等操作

## 2. 实现扫描任务队列系统

**问题分析**：
- 当前系统在扫描时会阻塞新的扫描请求
- 无法在扫描过程中添加新的扫描任务

**解决方案**：
- 实现扫描任务队列系统
- 允许同时添加多个扫描任务
- 扫描任务按顺序执行
- 前端显示待扫描队列

**实现步骤**：
1. 在后端添加任务队列管理
2. 创建 `scan_tasks` 表存储任务信息
3. 修改 `directory_routes.py` 为 `task_routes.py`，处理任务相关API
4. 前端添加待扫描任务列表显示
5. 实现任务状态管理（排队、运行中、完成、失败、取消）

## 3. 扩展扫描任务信息显示

**解决方案**：
- 扩展 `scan_tasks` 表，添加任务详细信息
- 修改任务显示组件，显示更多信息
- 计算并显示扫描耗时

**实现步骤**：
1. 创建 `scan_tasks` 表，包含以下字段：
   - id: 任务ID
   - directory_path: 扫描目录路径
   - status: 任务状态（排队、运行中、完成、失败、取消）
   - scan_started_at: 扫描开始时间
   - scan_ended_at: 扫描结束时间
   - total_files: 总文件数
   - processed_files: 已处理文件数
   - photo_count: 照片数量
   - video_count: 视频数量
   - duplicate_count: 重复文件数量
   - error_message: 错误信息
   - created_at: 任务创建时间
2. 修改 `scanner.py` 记录任务状态和时间
3. 创建 `TaskItem` 组件，显示任务详细信息
4. 计算并显示扫描耗时

## 4. 实现增量扫描功能

**解决方案**：
- 实现增量扫描，只扫描新增或修改的文件
- 在任务详情中显示增量扫描的信息

**实现步骤**：
1. 修改 `scanner.py` 实现增量扫描逻辑
2. 记录文件的修改时间和大小，用于判断是否需要重新扫描
3. 在数据库中存储文件的元数据
4. 修改前端显示，标识增量扫描的结果

## 5. 前端界面重构

**实现步骤**：
1. 重新组织页面布局，分为五个部分：
   - 创建新任务
   - 当前运行任务（显示进度）
   - 待执行任务队列
   - 历史任务列表
   - 任务详情
2. 实现任务管理功能：
   - 创建任务
   - 查看任务详情
   - 暂停任务
   - 取消任务
   - 编辑任务
   - 重新执行任务
3. 优化任务显示组件，显示详细的任务信息
4. 实现任务状态的视觉标识

## 6. 后端API重构

**实现步骤**：
1. 创建 `task_routes.py` 替代 `directory_routes.py`
2. 实现任务相关API：
   - POST /tasks: 创建新任务
   - GET /tasks: 获取任务列表
   - GET /tasks/{id}: 获取任务详情
   - PUT /tasks/{id}: 更新任务
   - DELETE /tasks/{id}: 删除任务
   - POST /tasks/{id}/pause: 暂停任务
   - POST /tasks/{id}/resume: 恢复任务
   - POST /tasks/{id}/cancel: 取消任务
   - POST /tasks/{id}/retry: 重新执行任务
3. 修改扫描逻辑，支持任务状态管理

## 7. 数据库结构调整

**实现步骤**：
1. 创建 `scan_tasks` 表，存储任务信息
2. 修改 `files` 表，添加文件元数据字段用于增量扫描
3. 关联 `files` 表与 `scan_tasks` 表

## 8. 任务管理功能实现

**实现步骤**：
1. 实现任务队列管理
2. 实现任务状态转换
3. 实现任务暂停/恢复功能
4. 实现任务取消功能
5. 实现任务重试功能

## 9. 性能优化

**实现步骤**：
1. 使用线程池管理扫描任务
2. 实现基于文件修改时间和大小的增量扫描
3. 优化数据库查询，提高扫描性能
4. 实现任务状态管理和进度跟踪
5. 提供清晰的用户界面反馈

通过这些优化，系统将变得更加高效、用户友好，能够更好地满足用户的需求，同时概念更加清晰，操作更加直观。
